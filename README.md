# MangaDex Lite

Небольшой нативный скачиватель MangaDex для Windows 10/11 x64.
**C# · WinUI 3 · .NET 10**. Русский интерфейс, без Python, браузерного движка,
gallery-dl и обязательного аккаунта. Реализация работает напрямую с MangaDex API;
код gallery-dl не копировался.

## Скачать и запустить

Готовые сборки: [Releases](https://github.com/maqsatto/MangaDexLite/releases/latest).

- **Portable**: распакуйте ZIP целиком и запустите `MangaDexLite.exe`.
  .NET и Windows App SDK включены; установщик не нужен.
- **Lite**: меньший архив, использующий установленные общие компоненты:
  [.NET 10 Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0) и
  [Windows App SDK 2.5 Runtime x64](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads).

Поддерживается Windows 10 версии 2004 (19041) или новее, x64.
Portable больше из-за включённых сред выполнения. WinUI 3 имеет собственную
стоимость по размеру и памяти; приложение не обещает размер в несколько мегабайт
для автономной версии. Исполняемые файлы пока не имеют цифровой подписи.

## Как пользоваться

1. Введите название или вставьте ссылку `https://mangadex.org/title/<UUID>`.
   Кнопка «Ещё результаты» открывает следующую порцию поиска.
2. Выберите тайтл, язык и группу перевода. «Все группы» показывает все релизы;
   один номер главы может встречаться несколько раз у разных групп.
3. Отметьте главы, нажмите «Выбрать все» или задайте диапазон, например `1`–`12.5`.
   Диапазон относится к номеру главы, независимо от тома. Главы без номера
   выбираются вручную. Внешние и недоступные главы не скачиваются.
4. Выберите папку. По умолчанию сохраняются оригинальные изображения.
   «Экономия трафика» использует сжатую версию MangaDex.
5. При необходимости включите «Собрать CBZ» и нажмите «Скачать выбранное».
   Выбранные главы образуют последовательную очередь; ошибки отдельных глав
   отображаются после её завершения.

«Отменить» оставляет уже сохранённые страницы. Повторный запуск тех же глав
пропускает их и докачивает недостающее. Готовые CBZ не перезаписываются.
Папки страниц сохраняются и при создании CBZ — это позволяет восстановить архив
без повторного скачивания. Для экономии места их можно удалить вручную после проверки CBZ.

Пути содержат UUID тайтла и главы, поэтому разные группы/языки не смешиваются.
Оригиналы и сжатые страницы хранятся отдельно. Служебные `.source.json` и
`.complete.json` относятся к докачке. Если страницы главы изменились на сервере,
программа попросит переместить старую папку вместо смешивания разных версий.

Настройки сохраняются при выборе папки и запуске загрузки в
`%LOCALAPPDATA%/MangaDexLite/settings.json`. Повреждённый файл сохраняется
без изменений, предупреждение появляется в интерфейсе. Для сброса переместите
его вручную и перезапустите приложение.

MangaDex может ограничивать доступность глав и частоту запросов. Приложение
обрабатывает HTTP 429 и временные ошибки с ограниченным числом повторов.
Удалённые, заблокированные и размещённые только у издателя главы не обходятся.
Сохраняйте материалы, которые вы вправе скачивать.

## Сборка

Нужны Windows x64, .NET 10 SDK и доступ к NuGet. Проект использует официальные
пакеты WindowsAppSDK.WinUI 2.3.9, WindowsAppSDK.Runtime 2.5.1 и Windows SDK BuildTools; Visual Studio
не обязателен для командной сборки. В Visual Studio используйте версию с
поддержкой .NET 10 и WinUI.

```powershell
./build.ps1 -Edition Portable
./build.ps1 -Edition Lite
```

Архивы появятся в `artifacts`. Не смешивайте содержимое разных сборок.

```powershell
dotnet run --project tests/MangaDexLite.Tests
dotnet run --project tests/MangaDexLite.Tests -- --live
dotnet build src/MangaDexLite -p:Platform=x64
```

Обычные тесты не используют сеть и не требуют стороннего тестового фреймворка.
`--live` дополнительно проверяет настоящий поиск, список русских глав и адреса
страниц MangaDex без скачивания изображений.
На интерактивной Windows-сессии `./smoke.ps1 -Executable <путь/MangaDexLite.exe>`
проверяет создание окна из опубликованной сборки и завершает тестовый процесс.

## Структура

- `src/MangaDexLite`: WinUI окно, выбор глав и последовательная очередь.
- `src/MangaDexLite.Core`: API, фильтры, безопасные пути, докачка, CBZ, настройки.
- `tests/MangaDexLite.Tests`: исполняемые проверки с HTTP-ответами из фикстур.
- `docs/design.md`: принятые границы и поведение приложения.
